СТРУКТУРА DJANGO ПРОЕКТА TERRA CARE
=====================================

КОРНЕВАЯ ДИРЕКТОРИЯ:
---------------------
manage.py                    - Главный скрипт Django
requirements.txt             - Зависимости Python
db.sqlite3                   - База данных (создается после migrate)

ДОКУМЕНТАЦИЯ:
-------------

ПРОЕКТ DJANGO (terracare/):
----------------------------
terracare/__init__.py        - Инициализация пакета
terracare/settings.py        - НАСТРОЙКИ ПРОЕКТА (важно!)
terracare/urls.py            - Главные URL маршруты
terracare/wsgi.py            - WSGI конфигурация

ПРИЛОЖЕНИЕ МАГАЗИНА (shop/):
-----------------------------
shop/__init__.py             - Инициализация приложения
shop/models.py               - МОДЕЛИ: Product, ProductImage, Order, OrderItem
shop/admin.py                - АДМИН ПАНЕЛЬ: настройка управления
shop/views.py                - VIEWS: обработка запросов, API
shop/urls.py                  - URL маршруты приложения
shop/apps.py                 - Конфигурация приложения
shop/migrations/__init__.py   - Папка для миграций БД

ШАБЛОНЫ HTML (templates/):
----------------------------
templates/base.html          - Базовый шаблон (навигация, модальные окна)
templates/shop/index.html    - Главная страница сайта

СТАТИЧЕСКИЕ ФАЙЛЫ (static/):
-----------------------------
static/css/styles.css        - СТИЛИ: темно-зеленый дизайн, большие буквы
static/js/app.js             - JAVASCRIPT: корзина, заказы, модальные окна
static/images/               - ИЗОБРАЖЕНИЯ: скопируйте сюда ваши фото
static/images/.gitkeep       - Инструкция для изображений

ДРУГИЕ ПАПКИ:
-------------
media/                       - Загружаемые файлы (создается автоматически)
locale/                      - Файлы переводов (для i18n)

run.bat                      - Быстрый запуск сервера (Windows)

ВАЖНЫЕ ФАЙЛЫ ДЛЯ ИЗМЕНЕНИЯ:
============================

1. НАСТРОЙКИ ПРОЕКТА:
   terracare/settings.py

   - TELEGRAM_CHAT_ID
   - LANGUAGES
   - DATABASES

2. ДИЗАЙН:
   static/css/styles.css
   - Цвета (переменные :root)
   - Размеры шрифтов
   - Стили компонентов

3. ЛОГИКА:
   static/js/app.js          - JavaScript логика
   shop/views.py              - Обработка на сервере

4. ТЕКСТЫ:
   templates/base.html        - Навигация, footer
   templates/shop/index.html  - Главная страница

5. ДАННЫЕ:
   shop/models.py             - Структура данных
   Админ панель /admin/       - Управление товарами


КОМАНДЫ:
========
python manage.py migrate          - Создать/обновить БД
python manage.py createsuperuser  - Создать администратора
python manage.py runserver         - Запустить сервер
python manage.py makemigrations    - Создать миграции


СТРУКТУРА БД:
=============
Product (Товар)
  - name_ky, name_ru, name_en
  - description_ky, description_ru, description_en
  - price, in_stock

ProductImage (Изображения)
  - product (связь)
  - image (файл)
  - order (порядок)

Order (Заказ)
  - customer_name, customer_phone, customer_address
  - status, total, sent_to_telegram

OrderItem (Позиции заказа)
  - order, product
  - quantity, price

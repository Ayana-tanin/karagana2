# 🗂️ ГДЕ ЧТО НАХОДИТСЯ - Быстрая навигация

## 📁 Основные папки Django проекта

```
КАРАГАНА/
│
├── 🎯 terracare/          ← НАСТРОЙКИ ПРОЕКТА
│   ├── settings.py        ← Здесь настраиваете Telegram, языки, БД
│   └── urls.py           ← Главные маршруты сайта
│
├── 🛍️ shop/              ← ПРИЛОЖЕНИЕ МАГАЗИНА (основная логика)
│   ├── models.py         ← МОДЕЛИ (Product, Order) - структура данных
│   ├── admin.py          ← АДМИН ПАНЕЛЬ - настройка управления товарами
│   ├── views.py          ← VIEWS - обработка запросов, API
│   └── urls.py           ← URL маршруты приложения
│
├── 🎨 templates/          ← HTML ШАБЛОНЫ
│   ├── base.html         ← Базовый шаблон (навигация, footer)
│   └── shop/
│       └── index.html    ← Главная страница
│
└── 📦 static/            ← СТАТИЧЕСКИЕ ФАЙЛЫ (CSS, JS, изображения)
    ├── css/
    │   └── styles.css    ← СТИЛИ (темно-зеленый дизайн)
    ├── js/
    │   └── app.js        ← JAVASCRIPT (корзина, заказы)
    └── images/           ← ИЗОБРАЖЕНИЯ (скопируйте сюда ваши фото)
```

## 🔧 ГДЕ ЧТО ИЗМЕНЯТЬ

### 1. Добавить/изменить товары
📍 **`shop/models.py`** - структура товара
📍 **Админ панель** `/admin/` - добавление товаров через интерфейс

### 2. Изменить дизайн
📍 **`static/css/styles.css`** - все стили
- Цвета: переменные `:root` в начале файла
- Размеры шрифтов: `.hero-title`, `.section-title`

### 3. Изменить логику корзины/заказов
📍 **`static/js/app.js`** - JavaScript логика
📍 **`shop/views.py`** - обработка заказов на сервере

### 4. Настроить Telegram
📍 **`terracare/settings.py`** - строки 140-141:
```python
TELEGRAM_BOT_TOKEN = 'ваш_токен'
TELEGRAM_CHAT_ID = 'ваш_chat_id'
```

### 5. Изменить тексты на сайте
📍 **`templates/shop/index.html`** - тексты на странице
📍 **`templates/base.html`** - тексты в навигации, footer

### 6. Добавить новые страницы
📍 **`shop/views.py`** - создать новую функцию view
📍 **`shop/urls.py`** - добавить маршрут
📍 **`templates/shop/`** - создать HTML шаблон

## 📊 СТРУКТУРА ДАННЫХ

### Product (Товар)
- `name_ky`, `name_ru`, `name_en` - названия
- `description_ky`, `description_ru`, `description_en` - описания
- `price` - цена
- `in_stock` - наличие

### ProductImage (Изображения товара)
- `product` - связь с товаром
- `image` - файл изображения
- Можно несколько изображений на товар

### Order (Заказ)
- `customer_name`, `customer_phone`, `customer_address` - данные клиента
- `status` - статус (new, processing, completed, cancelled)
- `total` - общая сумма
- `sent_to_telegram` - отправлен ли в Telegram

## 🚀 БЫСТРЫЙ СТАРТ

1. **Установка:**
   ```bash
   pip install -r requirements.txt
   python manage.py migrate
   python manage.py createsuperuser
   ```

2. **Запуск:**
   ```bash
   python manage.py runserver
   ```

3. **Открыть:**
   - Сайт: http://127.0.0.1:8000/
   - Админ: http://127.0.0.1:8000/admin/

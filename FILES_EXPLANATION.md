# Объяснение файлов проекта

## Корневая директория

### `manage.py`
Главный скрипт Django для управления проектом. Используется для всех команд.

### `requirements.txt`
Список Python пакетов, необходимых для проекта:
- Django - веб-фреймворк
- Pillow - работа с изображениями
- requests - отправка запросов в Telegram API

### `db.sqlite3`
База данных SQLite (создается автоматически после `migrate`)

---

## `terracare/` - Главный проект

### `settings.py`
**Главный файл настроек проекта:**
- `INSTALLED_APPS` - список установленных приложений
- `DATABASES` - настройки базы данных
- `STATIC_URL`, `MEDIA_URL` - пути к статическим файлам
- `LANGUAGES` - поддерживаемые языки (ky, ru, en)
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` - настройки Telegram

### `urls.py`
**Главные URL маршруты:**
- `/admin/` - админ панель
- `/` - главная страница (shop.urls)
- `/i18n/` - переключение языков

### `wsgi.py`
Конфигурация для деплоя на сервер

---

## `shop/` - Приложение магазина

### `models.py`
**Модели данных (таблицы в БД):**

1. **Product** - товары
   - `name_ky`, `name_ru`, `name_en` - названия на 3 языках
   - `description_ky`, `description_ru`, `description_en` - описания
   - `price` - цена
   - `in_stock` - наличие

2. **ProductImage** - изображения товаров
   - `product` - связь с товаром
   - `image` - файл изображения
   - `order` - порядок отображения

3. **Order** - заказы
   - `customer_name`, `customer_phone`, `customer_address` - данные клиента
   - `status` - статус заказа
   - `total` - общая сумма
   - `sent_to_telegram` - отправлен ли в Telegram

4. **OrderItem** - позиции заказа
   - `order` - связь с заказом
   - `product` - товар
   - `quantity` - количество
   - `price` - цена на момент заказа

### `admin.py`
**Настройка админ панели:**
- `ProductAdmin` - управление товарами с inline изображениями
- `OrderAdmin` - управление заказами с inline позициями

### `views.py`
**Обработчики запросов:**

1. `index(request)` - главная страница
   - Отображает шаблон `shop/index.html`

2. `get_products_json(request)` - API товаров
   - Возвращает JSON с товарами на текущем языке

3. `create_order(request)` - создание заказа
   - Принимает данные из формы
   - Создает Order и OrderItem
   - Отправляет в Telegram

### `urls.py`
**URL маршруты приложения:**
- `/` - главная страница
- `/api/products/` - API товаров
- `/api/order/` - создание заказа

---

## `templates/` - HTML шаблоны

### `base.html`
**Базовый шаблон:**
- Навигация с переключателем языков
- Кнопка корзины
- Модальные окна (корзина, оформление заказа, просмотр товара)
- Footer

### `shop/index.html`
**Главная страница:**
- Hero секция
- Секция товаров (динамически загружается через JS)
- Секция "О проекте"
- Секция "Миссия"

---

## `static/` - Статические файлы

### `css/styles.css`
**Стили сайта:**
- Темно-зеленые цвета (#0d2818, #1a4d2e, #2d5a3d)
- Большие заголовки (font-weight: 900, uppercase)
- Адаптивный дизайн
- Стили для модальных окон, корзины, форм

### `js/app.js`
**JavaScript логика:**
- Загрузка товаров через API
- Управление корзиной (localStorage)
- Модальные окна
- Отправка заказов
- Уведомления

### `images/`
**Изображения товаров:**
- main_page.jpg - главное изображение
- Изображения товаров (загружаются вручную)

---

## `media/` - Загружаемые файлы

**Создается автоматически:**
- `products/` - изображения товаров, загруженные через админ панель

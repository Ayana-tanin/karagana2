# Что нужно ввести для работы сайта

## 1. Telegram (заказы и заявки на карагану)

Чтобы заказы с сайта и заявки на сбор караганы приходили в Telegram, нужно указать два значения.

### Что ввести

| Переменная | Что ввести | Пример |
|------------|------------|--------|
| **TELEGRAM_BOT_TOKEN** | Токен бота от @BotFather | `7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` |
| **TELEGRAM_CHAT_ID** | ID чата, куда слать сообщения | `123456789` |

### Откуда взять

1. **TELEGRAM_BOT_TOKEN**
   - Откройте Telegram → найдите **@BotFather**.
   - Отправьте команду `/newbot`, придумайте имя и username бота.
   - BotFather пришлёт сообщение с **токеном** — длинная строка вида `123456789:AAH...`.  
   - Эту строку целиком и есть **TELEGRAM_BOT_TOKEN**.

2. **TELEGRAM_CHAT_ID**
   - Вариант А: напишите боту **@userinfobot** в Telegram — он пришлёт ваш **Id** (число). Это и есть **TELEGRAM_CHAT_ID** для личных сообщений вам.
   - Вариант Б: если бот должен писать в группу — добавьте бота в группу, напишите что-то в группе, затем откройте в браузере:  
     `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`  
     В ответе найдите `"chat":{"id": -123456789}` — это ID чата (может быть отрицательным для групп).

### Куда ввести

**Способ 1 — переменные окружения (удобно для разработки)**

Перед запуском сервера задайте переменные.

Windows (PowerShell):
```powershell
$env:TELEGRAM_BOT_TOKEN="сюда_ваш_токен"
$env:TELEGRAM_CHAT_ID="сюда_ваш_chat_id"
python manage.py runserver
```

Windows (CMD):
```cmd
set TELEGRAM_BOT_TOKEN=сюда_ваш_токен
set TELEGRAM_CHAT_ID=сюда_ваш_chat_id
python manage.py runserver
```

Linux / macOS:
```bash
export TELEGRAM_BOT_TOKEN="сюда_ваш_токен"
export TELEGRAM_CHAT_ID="сюда_ваш_chat_id"
python manage.py runserver
```

**Способ 2 — прямо в коде (не для продакшена)**

Откройте файл `terracare/settings.py` и замените значения по умолчанию:
```python
TELEGRAM_BOT_TOKEN = os.environ.get('TELEGRAM_BOT_TOKEN', 'сюда_ваш_токен')
TELEGRAM_CHAT_ID = os.environ.get('TELEGRAM_CHAT_ID', 'сюда_ваш_chat_id')
```

**Способ 3 — файл .env**

Скопируйте `.env.example` в `.env`, откройте `.env` и подставьте свои данные:
```
TELEGRAM_BOT_TOKEN=7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TELEGRAM_CHAT_ID=123456789
```
Чтобы Django читал `.env`, нужна библиотека `python-dotenv` и подключение в `settings.py` (при необходимости можно добавить по инструкции в интернете).

## 2. Админка Django (логин в админ-панель)

Для входа в админку: http://127.0.0.1:8000/admin/

Создайте суперпользователя один раз:
```bash
python manage.py createsuperuser
```

Вам нужно **ввести**:
- **Username** — логин (например `admin`).
- **Email** — ваш email (можно тестовый).
- **Password** — пароль (дважды, для подтверждения).

Эти же логин и пароль используйте при входе на страницу /admin/.

## 3. Картинки для сайта

Чтобы товары и главная страница отображались с фото, положите файлы в папку **`static/images/`**, например:

- `main_page.jpg` — главный баннер
- `soap2.JPG`, `soap3.JPG`, `soap4.PNG` — фото товаров
- при необходимости — другие изображения по названиям, которые указаны в админке у товаров

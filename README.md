# Terra Care - Django E-commerce Site

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Выполните миграции:
```bash
python manage.py migrate
```

3. Создайте суперпользователя для доступа к админ панели:
```bash
python manage.py createsuperuser
```

4. Скопируйте изображения в `static/images/`:
   - main_page.jpg
   - soap2.JPG, soap3.JPG, soap4.PNG
   - IMG_8132.PNG, IMG_8135.PNG, IMG_8136.PNG, IMG_8139.PNG
   - WhatsApp Image 2025-12-27 at 20.03.26.jpeg

5. Настройте Telegram Bot:
   - Создайте бота через @BotFather
   - Получите Bot Token
   - Получите Chat ID
   - Установите переменные окружения или измените в `terracare/settings.py`:
     ```python
     TELEGRAM_BOT_TOKEN = 'ваш_токен'
     TELEGRAM_CHAT_ID = 'ваш_chat_id'
     ```

6. Запустите сервер:
```bash
python manage.py runserver
```

7. Откройте в браузере:
   - Сайт: http://127.0.0.1:8000/
   - Админ панель: http://127.0.0.1:8000/admin/

## Использование админ панели

1. Войдите в админ панель с учетными данными суперпользователя
2. В разделе "Shop" вы можете:
   - Добавлять товары с названиями и описаниями на 3 языках
   - Загружать несколько изображений для каждого товара
   - Управлять заказами
   - Просматривать статусы заказов

## Особенности

- Мультиязычность (кыргызский, русский, английский)
- Корзина с сохранением в localStorage
- Оформление заказов с отправкой в Telegram
- Админ панель для управления товарами
- Современный дизайн в темно-зеленых тонах
- Адаптивная верстка
